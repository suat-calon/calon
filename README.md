# Calon

Calon is a Business OS for beauty and wellness businesses.

## Core systems

- booking engine
- subscription billing
- event backbone
- notification system
- worker queue

## Stack

- NestJS
- PostgreSQL
- Redis
- Prisma
- TurboRepo
- Docker
